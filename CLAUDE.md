## Agent skills

### Issue tracker

Las issues se registran en GitHub Issues (ulidev/rooms76) y se gestionan con el CLI `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Se usan las cinco etiquetas por defecto: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: un `CONTEXT.md` y `docs/adr/` en la raíz del repo. See `docs/agents/domain.md`.
